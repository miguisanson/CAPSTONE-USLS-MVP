Demo Flow For Monday

  1. Create a student handoff. Simulate an AIMS/admission handoff.
  2. Run a course audit. Pick the same student, mark one subject completed/current/missing, and watch the missing count update.
  3. Check research readiness. Use Form 1 or Form 4 and mark missing items to create a next-owner task.
  4. Match a panel. Enter a specialization and let the system score faculty by specialization, availability, and workload.
  5. Schedule a defense. Pick a date; the app confirms only when assigned panel availability matches.
  6. Show the activity trail. Each completed action leaves an audit-style event for the student.

What The System Is Doing

The user is not entering dashboard numbers manually. The indicators are derived from live student data: student standing, course evidence, document checks, faculty availability, panel assignments, schedule results, and pending owner tasks.
